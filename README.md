✨ Features

🏨 Detailed Room Listings: Browse available rooms complete with photos, amenities, pricing, and precise room sizes (sq ft / sq m).
🔍 Smart Search & Filters: Filter rooms by price range, capacity, room dimensions, availability dates, and amenities.
💳 Integrated Payment Gateways: Support for multiple secure payment methods (e.g., Credit/Debit Cards, PayPal, Stripe, Digital Wallets).
📅 Real-Time Reservation System: Check live room availability and make instant bookings without double-booking conflicts.
📱 Responsive Design: Fully optimized experience across desktop, tablet, and mobile devices.
👤 User Dashboard: Manage past and upcoming bookings, download invoices, and view reservation statuses.
